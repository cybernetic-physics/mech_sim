# Shaft collar clearance

Design a shaft (Ø8.527 mm) running through a fixed collar.

* `params.shaft_diameter_mm` must equal 8.527.
* `params.collar_inner_diameter_mm` minus the shaft diameter must be ≥ 0.2 mm.
* Required ports: `shaft_origin`, `collar_face` (collar_face grounded).
* Mobility = 0.
