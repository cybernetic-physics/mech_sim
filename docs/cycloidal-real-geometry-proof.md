# Cycloidal Real-Geometry Chrono Proof

This proof is a solver smoke for the FreeCAD/OCCT-to-Chrono path. It is not
hardware calibration and it is not a claim that the observed transmission ratio
matches a physical reducer.

The checked-in proof JSON is generated by:

```bash
MECH_BENCH_FREECAD_CMD=/tmp/corl-freecad-env/bin/freecadcmd \
MECH_BENCH_CYCLOID_GEARBOX_PATH=/tmp/CycloidGearBox \
PYTHONPATH=/tmp/corl-chrono-env/lib/python3.12/site-packages \
uv run --extra dev python scripts/prove_cycloidal_chrono_real_geometry.py \
  --out-dir /tmp/mech_bench_cycloidal_real_geometry_proof \
  --proof-json docs/cycloidal_real_geometry_proof.json
```

Acceptance requires:

- FreeCAD/CycloidGearBox writes `cycloidal_assets_manifest.json`.
- All seven named reducer bodies have nonempty STEP and STL exports.
- The Chrono DesignIR uses non-procedural Chrono collision for `pinDisk`,
  `driverDisk`, and `cycloidalDisk1`, backed by exported CAD meshes and
  CAD-derived feature frames.
- `_chrono_impl.run(...)` runs with `procedural_cycloidal_fallback=false`.
- Both NSC and SMC emit finite real-geometry metrics:
  `lockup_detected`, `ratio_observed`, `out_omega_med`,
  `max_penetration_mm`, `n_contacts_max`, `contact_force_rms_N`, and
  `top_contact_pairs`.
