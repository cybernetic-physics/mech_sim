# Cycloidal Real-Geometry Chrono Proof

This proof is a solver acceptance packet for the FreeCAD/OCCT-to-Chrono path.
It is not hardware calibration. It proves that generated CAD assets can drive
non-procedural Chrono NSC/SMC runs, that unloaded SMC ratio is near the declared
reducer ratio, and that the loaded SMC case fails on power/torque metrics rather
than artificial jam.

The checked-in proof JSON is generated by:

```bash
MECH_BENCH_FREECAD_CMD=/tmp/corl-freecad-env/bin/freecadcmd \
MECH_BENCH_CYCLOID_GEARBOX_PATH=/tmp/CycloidGearBox \
PYTHONPATH=/tmp/corl-chrono-env/lib/python3.12/site-packages \
uv run --extra dev python scripts/prove_cycloidal_chrono_real_geometry.py \
  --out-dir /tmp/mech_bench_cycloidal_real_geometry_proof \
  --proof-json docs/cycloidal_real_geometry_proof.json
```

Acceptance requires:

- FreeCAD/CycloidGearBox writes `cycloidal_assets_manifest.json`.
- All seven named reducer bodies have nonempty STEP and STL exports.
- CAD datums include the expected ring pins, driver pins, and output-hole
  feature frames.
- Static contact audit reports finite ring/disc and driver/disc distances
  plus positive driver-pin/output-hole radial clearance.
- The trusted asset manifest records FreeCAD/OCCT recomputed mass, COM,
  and inertia for every positive-mass body.
- The Chrono DesignIR uses non-procedural Chrono collision for `pinDisk`,
  `driverDisk`, and `cycloidalDisk1`, backed by exported CAD meshes and
  CAD-derived feature frames.
- `_chrono_impl.run(...)` runs with `procedural_cycloidal_fallback=false`.
- Loaded NSC enters the known bad rigid-contact regime with excessive contacts
  and penetration.
- Loaded SMC clears the minimum non-lockup threshold with bounded penetration,
  finite ratio, and lower contact count/force than NSC.
- Unloaded SMC reports ratio within 15% of the declared ratio.
- SMC ratio convergence across sample counts 41/61/81 stays within the proof
  tolerance.
- The proof also records non-gating SMC timestep-sensitivity diagnostics. These
  currently document whether the CAD/contact setup is stable under timestep
  refinement; they are not yet treated as a passing validation claim.
- NSC, loaded SMC, and unloaded SMC emit finite real-geometry metrics:
  `lockup_detected`, `ratio_observed`, `out_omega_med`,
  `max_penetration_mm`, `n_contacts_max`, `contact_force_rms_N`, and
  `top_contact_pairs`.
